# Observer Pattern - Carrello

Progetto realizzato durante il percorso Full Stack Developer
di start2impact.

## Obiettivo

Implementare il Design Pattern Observer attraverso
la simulazione di un carrello e-commerce interattivo.

## Tecnologie utilizzate

- HTML5
- CSS3
- JavaScript ES6+

## Funzionalità

- Aggiunta e rimozione dei prodotti
- Aggiornamento automatico del contatore
- Registrazione delle operazioni nella console
- Attivazione e disattivazione degli osservatori
- Gestione delle iscrizioni e disiscrizioni

## Concetti di programmazione

- Observer Design Pattern
- Programmazione orientata agli oggetti (OOP)
- Classi ed ereditarietà
- Set e Map
- Getter
- Arrow Functions
- Destructuring
- Spread Operator
- Manipolazione del DOM
- Event Listener
- Cleanup Functions

## Avvio del progetto

Aprire il file index.html nel browser oppure
utilizzare l'estensione Live Server di Visual Studio Code.
